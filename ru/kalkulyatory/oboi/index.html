Обои

Сколько рулонов, с раппортом рисунка.

Каталог строительных материалов — 1 материалов в каталоге

Как мы это считаем

Что вводишь

  • Ширина (м)
  • Высота (м)
  • Ширина рулона (м)
  • Длина рулона (м)
  • Раппорт рисунка (м, 0 = нет)

Формула

полоса = Раппорт рисунка > 0 → ⌈ Высота ÷ Раппорт рисунка ⌉ × Раппорт рисунка; иначе Высота
полос нужно = ⌈ Ширина ÷ Ширина рулона ⌉
полос из рулона = ⌊ Длина рулона ÷ полоса ⌋
рулоны = ⌈ полос нужно ÷ полос из рулона ⌉

Пример

Значения по умолчанию из формы, прогнанные через то же ядро:

Купить
3 рулонов

На что обратить внимание

У обоев с раппортом каждая полоса удлиняется до целой кратности раппорта, поэтому из рулона выходит меньше полос. Раппорт 0 означает обои без рисунка для подгонки.
