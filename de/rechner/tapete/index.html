So rechnen wir

Was du eingibst

  • Breite (m)
  • Höhe (m)
  • Rollenbreite (m)
  • Rollenlänge (m)
  • Rapport (m, 0 = keiner)

Formel

Bahn = Rapport > 0 → ⌈ Höhe ÷ Rapport ⌉ × Rapport; sonst Höhe
Bahnen nötig = ⌈ Breite ÷ Rollenbreite ⌉
Bahnen je Rolle = ⌊ Rollenlänge ÷ Bahn ⌋
Rollen = ⌈ Bahnen nötig ÷ Bahnen je Rolle ⌉

Beispiel

Die Standardwerte aus dem Formular, durch denselben Rechenkern geschickt:

Zu kaufen
3 Rollen

Worauf du achten solltest

Bei Rapport wird jede Bahn auf ein volles Vielfaches des Rapports verlängert, aus einer Rolle kommen also weniger Bahnen. Rapport 0 heißt Tapete ohne anzupassendes Muster.

Die LiczMat-App für Android nutzt dieselbe Formel. Die Rechenkerne der Website sind 1:1-Portierungen des App-Codes.
