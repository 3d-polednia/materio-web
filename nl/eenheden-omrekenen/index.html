Hoe we het berekenen

Elke categorie heeft een basiseenheid. De waarde gaat naar de basiseenheid en van daar naar de doeleenheid, dus elk paar eenheden werkt op dezelfde manier.

Temperatuur is de uitzondering: de schalen verschillen ook in hun nulpunt, dus °C, °F en K gaan via graden Celsius en niet via een factor.

De motor van de site is een 1-op-1-omzetting van de code van de Android-app.

Wat het omrekent

  • Lengte — mm, cm, dm, m, km, in, ft, yd, mi, nmi
  • Oppervlak — mm², cm², dm², m², a, ha, km², in², ft², yd², ac, mi²
  • Volume — ml, cl, l, m³, cm³, dm³, gal, qt, pt, fl oz, ft³
  • Massa — mg, g, dag, kg, t, oz, lb, st
  • Temperatuur — °C, °F, K
  • Snelheid — m/s, km/h, mph, kn, ft/s
  • Tijd — ms, s, min, h, d, wk
  • Druk — Pa, hPa, kPa, bar, mbar, atm, psi, mmHg
  • Energie — J, kJ, cal, kcal, Wh, kWh
  • Vermogen — W, kW, MW, hp, KM
  • Data — B, kB, MB, GB, TB, KiB, MiB, GiB
