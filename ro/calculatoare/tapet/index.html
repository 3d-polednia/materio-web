Tapet

Câte role, cu raportul modelului.

Cum calculăm

Ce introduci

  • Lățime (m)
  • Înălțime (m)
  • Lățime rolă (m)
  • Lungime rolă (m)
  • Raport model (m, 0 = fără)

Formula

fâșie = Raport model > 0 → ⌈ Înălțime ÷ Raport model ⌉ × Raport model; altfel Înălțime
fâșii necesare = ⌈ Lățime ÷ Lățime rolă ⌉
fâșii dintr-o rolă = ⌊ Lungime rolă ÷ fâșie ⌋
role = ⌈ fâșii necesare ÷ fâșii dintr-o rolă ⌉

Exemplu

Valorile implicite din formular, trecute prin același motor:

De cumpărat
3 role

La ce să fii atent

La tapetul cu raport fiecare fâșie se lungește la un multiplu întreg al raportului, deci dintr-o rolă ies mai puține fâșii. Raport 0 înseamnă tapet fără model de potrivit.

Aplicația Materio pentru Android folosește aceeași formulă. Motorul de calcul al site-ului este un port 1:1 al codului din aplicație.
