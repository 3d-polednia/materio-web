Suspended ceiling

CD/UD profiles, hangers and boards.

Building material catalogue — 5 materials in the catalogue

How we calculate it

What you enter

  • Width (m)
  • Length (m)
  • CD spacing (m)
  • Hanger spacing (m)

Formula

CD runs = ⌊ Width ÷ CD spacing ⌋ + 1
CD profiles = ⌈ CD runs × Length ÷ 4 ⌉
UD profiles = ⌈ 2 × (Width + Length) ÷ 3 ⌉
hangers = CD runs × (⌊ Length ÷ Hanger spacing ⌋ + 1)
boards = ⌈ Width × Length × 1.10 ÷ 2.4 ⌉

What to watch out for

40 cm CD spacing and 90 cm hanger spacing is a typical ceiling under one board. Heavier loads need tighter spacing.
